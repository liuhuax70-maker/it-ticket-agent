# 常见网络问题 FAQ

## 无线网络经常掉线怎么办？

优先确认是否处在信号盲区，可尝试切换到 5GHz 频段。若同一位置多台设备同时掉线，多为 AP 过载，请提交工单并注明楼层与 AP 编号。

## 内网系统访问很慢如何排查？

先确认是否为 VPN 分流问题，非内网网段走公网会明显变慢。可在客户端执行 tracert 查看跳数，超过 8 跳通常说明绕行外网。

## 能上微信但打不开内网页面是什么原因？

通常是 DNS 解析失败。请确认 DNS 服务器地址未被手动修改为公网 DNS，内网域名必须由公司 DNS 解析。

## 有线网络提示 IP 冲突怎么处理？

多为手工设置了静态 IP。请将网卡改回自动获取（DHCP），或向网络组申请保留地址。

## 访客如何接入公司网络？

访客网络为独立 SSID，需由接待人在访客管理系统登记后获取当日有效的一次性密码，密码 8 小时内有效。
