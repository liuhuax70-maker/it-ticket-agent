# 终端防护平台使用手册

## 适用版本

本手册适用于终端防护客户端 v5.0.1 至 v5.2.0。v4.x 客户端已进入维护期，不再提供新特性。

## 功能模块

客户端包含病毒防护、行为监控、外设管控与漏洞修复四个模块。病毒防护默认开启实时扫描，行为监控需管理员在控制台下发策略后生效。

## 常见错误码

ERR-8801：病毒库已过期。病毒库超过 7 天未更新会触发该错误，请在内网更新服务器同步最新病毒库。

ERR-8804：文件被隔离。疑似威胁文件会被移入隔离区，可从客户端「隔离区」恢复并加入白名单。

ERR-8809：客户端离线。多为 agent 服务被停止或内网更新服务器不可达，请检查 agent 进程状态。

## 隔离与白名单

被隔离文件保留 30 天，逾期自动清除。确认安全的文件可在隔离区恢复并加入白名单，白名单条目需管理员审批。

## 排障清单

- 确认 agent 服务（epp-agent）处于运行状态。
- 确认能访问内网更新服务器 update.corp.example.com。
- 确认病毒库更新时间在 7 天以内。
